# Resonance Developer Skill (`resonance-developer`)

Use this skill whenever working on backend microservices across `resonance-office/`, `resonance-dependency/`, or `resonance-unified-context/`.
This skill guides the implementation flow from **Contract-First Specification** to **Clean Architecture Implementation** and **Evidence-Gated Guardrail Verification**.

Before making code or architectural decisions, read and apply [resonance-developer.mini.md](resonance-developer.mini.md).
Use [resonance-developer.md](resonance-developer.md) for full reference code templates and in-depth explanations, and [resonance-developer.nano.md](resonance-developer.nano.md) when working under strict context budget constraints.
