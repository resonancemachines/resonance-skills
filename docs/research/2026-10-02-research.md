## 1. Executive Summary & Problem Space

Enterprise Company Brain platforms require indexing semi-structured and unstructured file systems (PDFs, Markdown, DOCX, Codebases, Confluence exports, technical specifications) into an actionable knowledge graph combined with dense semantic vector stores. 

In the **Resonance Platform**, this functionality is delivered via **Continuous GraphRAG**, integrating:
1. **Unstructured File Storage:** MinIO Object Storage (S3-compatible, on-premise/cloud-agnostic).
2. **Relational & Dense Retrieval:** PostgreSQL 16 with `pgvector` (HNSW cosine distance) and `tsvector` (BM25 lexical scoring).
3. **Semantic Structural Graph:** Neo4j 5.20 with Schema.org ontology traversal.
4. **Event Streaming Mesh:** Redpanda (Kafka-compatible, C++ Raft-native).
5. **Decoupled Outbox Capture:** Debezium Connect 2.7 monitoring PostgreSQL Write-Ahead Logs (WAL).

### Current System Bottlenecks Identified
Prior to this research, document ingestion and synchronization operated under full-document batch semantics:
1. **Full-Document Reprocessing Penalty:** When an existing document was edited or partially appended in the file system, `DocumentVectorizationService` executed `deleteByTenantIdAndDocumentId(tenantId, documentId)` and re-embedded all chunks. Similarly, `GraphProjectionService` re-ran comprehensive entity extraction and graph wiring. For a 200-page specification, a 1-paragraph edit required hundreds of LLM embedding calls and thousands of Cypher edge queries, generating unacceptable CPU spikes and delaying knowledge freshness.
2. **Cross-Store Consistency Drift (Dual-Write Anti-Pattern):** Writing to PostgreSQL `document_embeddings` followed by an asynchronous or sequential write to Neo4j resulted in potential consistency divergence whenever transient network partitions or Neo4j leader elections occurred.
3. **Cache Invalidation Blindness:** Multi-agent swarms issue dozens of concurrent reasoning queries against shared tenant documents. Existing query caches in `resonance-research` utilized coarse time-based expiration (`expireAfterWrite(5m)` via Caffeine) or global `invalidateAll()` purges. Coarse TTL allowed agents to act on stale knowledge, while global purges thrashed JVM caches and spiked search latency above the strict **4.0-second SLA**.

### 2.1 Operational Overhead
- **No Polling Anti-Patterns:** In compliance with [ADR 0001](../adr/0001-transactional-outbox-event-structure.md), `@Scheduled` database pollers and interval query scrapers are forbidden. Mutation detection is entirely pushed by PostgreSQL WAL via Debezium CDC into Redpanda topics.
- **Zero Cloud Lock-in:** No dependence on AWS EventBridge, SQS/SNS, DynamoDB Streams, GCP Pub/Sub, or Azure Blob Events. The entire pipeline runs identically on local Docker Compose, bare-metal Kubernetes (K3s/RKE2), or private clouds.
- **Zero Daemon Overhead for Storage:** MinIO native bucket notifications emit events directly to Redpanda upon multipart completion, eliminating intermediary file-watching daemons.

### 2.2 Scalability Boundaries
- **Computational Complexity Reduction:** Shifting from full-document re-chunking to content-hash delta identification reduces compute complexity from $\mathcal{O}(N)$ to $\mathcal{O}(\Delta)$ where $\Delta \ll N$. Unchanged chunks bypass embedding models and Cypher traversals.
- **Linearized Ordering Guarantee:** By configuring Debezium Single Message Transforms (SMTs) to route chunk changes with the partition key `hash(tenant_id, document_id)`, Redpanda guarantees per-document strict serialization across partitions without requiring cross-partition distributed locking.
- **Memory Footprint Bounds:** Semantic caching is partitioned into a two-tier in-memory model bounded by Caffeine W-TinyLFU eviction policies, preventing out-of-memory (OOM) conditions during large document ingestions.

### 2.3 Multi-Tenancy Isolation
- **Relational Tier:** PostgreSQL Row-Level Security (RLS) is applied to `document_chunks`, `document_embeddings`, and `outbox_events`. Every connection checks:
  ```sql
  ALTER TABLE document_chunks ENABLE ROW LEVEL SECURITY;
  CREATE POLICY tenant_isolation_policy ON document_chunks
      USING (tenant_id = current_setting('app.current_tenant_id', true));
  ```
- **Graph Tier:** In Neo4j, multi-tenancy is enforced via parameterized Cypher. Node labels and edge relationships carry `tenantId`. Dynamic label interpolation is strictly prohibited:
  ```cypher
  MATCH (t:Tenant {id: $tenantId})-[:OWNS]->(d:Document {id: $documentId})
  MATCH (d)-[:CONTAINS_CHUNK]->(c:Chunk {tenantId: $tenantId})
  WHERE c.id = $chunkId
  RETURN c;
  ```
- **Cache Isolation:** Cache keys are prefixed with `${tenantId}:${workspaceId}:`, ensuring that cryptographic hash lookups are strictly partitioned by tenant boundaries.

### 2.4 Developer Velocity
- **Strict Java 21 Typing:** All events, domain models, and DTOs leverage Java 21 `record` types, sealed interfaces, and pattern matching.
- **Declarative Frameworks:** Spring Boot 3.3+/4.x annotations, Spring AI `EmbeddingModel`, Spring Data Neo4j `Neo4jClient`, and Spring Kafka container factories provide clean, testable developer abstractions.
- **Contract-First Schemas:** Protobuf `.proto` schemas registered in Redpanda Schema Registry with `BACKWARD_TRANSITIVE` compatibility guarantee that schema changes in ingestion microservices do not break downstream context consumers.

### 3.1 Front-Office Interaction: Outbox Pattern & Direct-to-Store Ingestion
1. **Multipart Upload Negotiation:** Client contacts `resonance-upload` (`:8008`). The service creates an upload session in PostgreSQL and returns presigned MinIO S3 multipart upload URLs.
2. **Direct Data Plane Transfer:** Client streams file chunks directly into MinIO (`:9000`), completely bypassing the Spring Boot JVM memory heap.
3. **Assembly & Hash Verification:** Client issues `CompleteUpload` with a SHA-256 digest of the entire object. `resonance-upload` verifies the assembled object against MinIO and writes an `UploadCompletedEvent` into its local PostgreSQL `outbox_events` table in the same transaction.
4. **CDC Event Propagation:** Debezium captures the outbox insert from the PostgreSQL WAL and streams `resonance.document.uploaded` to Redpanda (`:19092`).

### 3.2 Middle-Office Interaction: Choreographed Sagas & Governance
1. **Saga Orchestration:** `resonance-workflow` (`:8108`) receives `resonance.document.uploaded` and initiates the document ingestion saga.
2. **Streaming Metadata Extraction:** `resonance-meta` (`:8109`) reads the object stream from MinIO and utilizes Apache Tika to extract raw text, MIME types, and document structural blocks without persisting files to local disk.
3. **PII Tokenization Interceptor:** Extracted text is filtered through `resonance-crypto` (`:8103`). Any recognized PII (emails, SSNs, phone numbers) is tokenized into irreversible cryptographic tokens stored in the secure token vault, ensuring zero plaintext PII enters downstream vector or graph stores.
4. **Context Ingestion Dispatch:** Sanitized text blocks and structural metadata are dispatched to `resonance-unified-context`.

### 3.3 Back-Office & Platform Brain: Incremental CDC Synchronization
1. **Delta Chunking Algorithm:** 
   - Incoming document text is chunked into overlapping windows (512 tokens with 64-token overlap).
   - Each chunk receives a deterministic content hash: `chunkHash = SHA-256(chunkIndex + ":" + chunkContent)`.
   - Existing chunk hashes for `(tenantId, documentId)` are queried from PostgreSQL.
   - The engine categorizes chunks into:
     * **Unchanged:** Identical hash $\rightarrow$ skipped entirely.
     * **Created:** New chunk index $\rightarrow$ embedded and inserted.
     * **Updated:** Same index, altered hash $\rightarrow$ embedded and updated.
     * **Deleted:** Superfluous indices $\rightarrow$ removed.
2. **Atomic Relational Persistence:** Created and updated chunks are saved in PostgreSQL `document_chunks`.
3. **Debezium WAL Capture:** Debezium monitors `document_chunks`. For every row mutation, it emits a standardized CDC payload to `cdc.resonance.document_chunks` keyed by `${tenant_id}:${document_id}`.
4. **Targeted Subgraph Cypher Mutation:** `IncrementalGraphProjectionService` consumes the CDC stream. Instead of dropping document nodes, it applies localized Cypher delta statements (`MERGE`, `ON MATCH SET`, `DETACH DELETE`) directly targeting mutated chunks and referenced Schema.org entities.

### 3.4 Two-Tier Reciprocal Rank Fusion (RRF) Semantic Caching
The query façade in `resonance-research` and the search engine in `resonance-unified-context` share a two-tier caching architecture:

```
User Query ──> [Query Normalization]
                     │
                     ▼
           [Tier 1: Query Vector Cache]
           (LRU in-memory: Normalized Query -> float[] Embedding)
                     │
                     ├── Cache Hit: Skip Embedding Inference (saves ~120ms)
                     └── Cache Miss: Invoke Spring AI EmbeddingModel
                     │
                     ▼
           [Tier 2: RRF Candidate Fusion Cache]
           (W-TinyLFU: {tenantId}:{workspaceId}:{hash(query)} -> List<SearchResult>)
                     │
                     ├── Cache Hit (<20ms): Return fused candidate ranking directly
                     └── Cache Miss:
                           ├── Parallel Neo4j Cypher Traversal (<= 350ms)
                           ├── Parallel PostgreSQL pgvector Cosine Search (<= 450ms)
                           ├── Parallel PostgreSQL tsvector BM25 Search (<= 150ms)
                           └── Reciprocal Rank Fusion Blending (<= 50ms)
                           └── Populate Tier 2 Cache with Invalidation Tags
```

### 3.5 Real-Time Semantic Invalidation Bus
To guarantee sub-second freshness without stale read hazards:
- When a document chunk mutation event arrives on `cdc.resonance.document_chunks`, the `SemanticCacheInvalidationBus` extracts `tenantId`, `documentId`, and `chunkId`.
- The bus queries an inverted index of `{documentId} -> Set<CacheKey>` maintained within the cache manager.
- All cached query results containing the affected document or chunk are invalidated within $\le 250\text{ ms}$, ensuring zero stale agent responses without global cache purges.

### 5.2 Idempotent Debezium CDC Consumer for Document Chunks

```java
package com.resonancemachines.context.cdc;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.resonancemachines.context.common.dto.BrainIngestionEvent.ChunkCdcEvent;
import com.resonancemachines.context.graph.IncrementalGraphProjectionService;
import com.resonancemachines.context.search.SemanticCacheInvalidationBus;
import io.micrometer.core.instrument.MeterRegistry;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.support.Acknowledgment;
import org.springframework.kafka.support.KafkaHeaders;
import org.springframework.messaging.handler.annotation.Header;
import org.springframework.messaging.handler.annotation.Payload;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.Objects;

/**
 * Idempotent Consumer processing Debezium PostgreSQL WAL CDC events.
 * Keyed by: hash(tenant_id, document_id) to guarantee linear execution.
 */
@Component
public class DocumentChunkCdcConsumer {

    private static final Logger log = LoggerFactory.getLogger(DocumentChunkCdcConsumer.class);
    private static final String TOPIC = "cdc.resonance.document_chunks";
    private static final String GROUP_ID = "graphrag-cdc-sync-group";

    private final ObjectMapper objectMapper;
    private final IncrementalGraphProjectionService graphProjectionService;
    private final SemanticCacheInvalidationBus invalidationBus;
    private final JdbcTemplate jdbcTemplate;
    private final MeterRegistry meterRegistry;

    public DocumentChunkCdcConsumer(
            ObjectMapper objectMapper,
            IncrementalGraphProjectionService graphProjectionService,
            SemanticCacheInvalidationBus invalidationBus,
            JdbcTemplate jdbcTemplate,
            MeterRegistry meterRegistry) {
        this.objectMapper = objectMapper;
        this.graphProjectionService = graphProjectionService;
        this.invalidationBus = invalidationBus;
        this.jdbcTemplate = jdbcTemplate;
        this.meterRegistry = meterRegistry;
    }

    @KafkaListener(
            topics = TOPIC,
            groupId = GROUP_ID,
            containerFactory = "manualAckKafkaListenerContainerFactory"
    )
    @Transactional
    public void onChunkCdcMessage(
            @Payload String payload,
            @Header(KafkaHeaders.RECEIVED_KEY) String messageKey,
            @Header(KafkaHeaders.RECEIVED_PARTITION) int partition,
            @Header(KafkaHeaders.OFFSET) long offset,
            Acknowledgment acknowledgment) {

        log.debug("Consuming CDC event: key={}, partition={}, offset={}", messageKey, partition, offset);

        try {
            ChunkCdcEvent cdcEvent = objectMapper.readValue(payload, ChunkCdcEvent.class);
            
            // 1. Idempotency Check via Deduplication Ledger
            String eventId = String.format("cdc:%d:%d", partition, offset);
            if (!acquireDeduplicationLock(eventId, cdcEvent.tenantId())) {
                log.info("Duplicate CDC event detected (skipping): eventId={}", eventId);
                acknowledgment.acknowledge();
                return;
            }

            // 2. Route Operation Pattern Matching (Java 21 switch)
            switch (cdcEvent.operation()) {
                case "c", "r" -> handleChunkCreated(cdcEvent);
                case "u"      -> handleChunkUpdated(cdcEvent);
                case "d"      -> handleChunkDeleted(cdcEvent);
                default       -> log.warn("Ignored CDC operation: {}", cdcEvent.operation());
            }

            // 3. Trigger Targeted Cache Invalidation
            String docId = cdcEvent.after() != null ? cdcEvent.after().documentId() : cdcEvent.before().documentId();
            String chunkId = cdcEvent.after() != null ? cdcEvent.after().id().toString() : cdcEvent.before().id().toString();
            invalidationBus.publishInvalidation(cdcEvent.tenantId(), docId, chunkId);

            // 4. Acknowledge message offset
            acknowledgment.acknowledge();
            meterRegistry.counter("graphrag.cdc.processed", "op", cdcEvent.operation()).increment();

        } catch (Exception e) {
            log.error("Failed to process CDC record at partition={}, offset={}: {}", partition, offset, e.getMessage(), e);
            meterRegistry.counter("graphrag.cdc.errors").increment();
            // Do NOT acknowledge to allow Kafka retry / DLQ fallback
            throw new RuntimeException("CDC processing failed, redelivery requested", e);
        }
    }

    private void handleChunkCreated(ChunkCdcEvent event) {
        var state = Objects.requireNonNull(event.after(), "After state must not be null for create");
        log.info("CDC CREATE: tenant={}, doc={}, chunkIdx={}", state.tenantId(), state.documentId(), state.chunkIndex());
        graphProjectionService.syncChunkUpsert(state);
    }

    private void handleChunkUpdated(ChunkCdcEvent event) {
        var state = Objects.requireNonNull(event.after(), "After state must not be null for update");
        log.info("CDC UPDATE: tenant={}, doc={}, chunkIdx={}", state.tenantId(), state.documentId(), state.chunkIndex());
        graphProjectionService.syncChunkUpsert(state);
    }

    private void handleChunkDeleted(ChunkCdcEvent event) {
        var state = Objects.requireNonNull(event.before(), "Before state must not be null for delete");
        log.info("CDC DELETE: tenant={}, doc={}, chunkIdx={}", state.tenantId(), state.documentId(), state.chunkIndex());
        graphProjectionService.syncChunkDelete(state);
    }

    private boolean acquireDeduplicationLock(String eventId, String tenantId) {
        String sql = """
                INSERT INTO cdc_processed_events (event_id, tenant_id, processed_at)
                VALUES (?, ?, CURRENT_TIMESTAMP)
                ON CONFLICT (event_id) DO NOTHING;
                """;
        int rows = jdbcTemplate.update(sql, eventId, tenantId);
        return rows > 0;
    }
}
```

### 5.3 Parameterized Cypher Incremental Subgraph Projector

```java
package com.resonancemachines.context.graph;

import com.resonancemachines.context.common.dto.BrainIngestionEvent.ChunkRowState;
import com.resonancemachines.context.common.dto.BrainIngestionEvent.ExtractedEntityDto;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.data.neo4j.core.Neo4jClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.Map;
import java.util.Objects;

/**
 * Projects individual chunk mutations into Neo4j incrementally.
 * Guarantees zero cross-tenant bleed by binding $tenantId on every Cypher statement.
 */
@Service
public class IncrementalGraphProjectionService {

    private static final Logger log = LoggerFactory.getLogger(IncrementalGraphProjectionService.class);
    private final Neo4jClient neo4jClient;

    public IncrementalGraphProjectionService(Neo4jClient neo4jClient) {
        this.neo4jClient = neo4jClient;
    }

    /**
     * Atomically upserts an individual Chunk node and wires relationships to
     * Document and Schema.org extracted entities.
     */
    @Transactional
    public void syncChunkUpsert(ChunkRowState state) {
        Objects.requireNonNull(state, "ChunkRowState must not be null");
        String tenantId = state.tenantId();
        String documentId = state.documentId();
        String chunkId = state.id().toString();

        log.debug("Executing Cypher delta upsert: chunkId={}, tenantId={}", chunkId, tenantId);

        // 1. Upsert Chunk Node and link to parent Document
        String chunkCypher = """
                MATCH (t:Tenant {id: $tenantId})-[:OWNS]->(d:Document {id: $documentId})
                MERGE (c:Chunk {id: $chunkId, tenantId: $tenantId})
                ON CREATE SET c.chunkIndex = $chunkIndex,
                              c.contentHash = $contentHash,
                              c.updatedAt = timestamp()
                ON MATCH SET c.chunkIndex = $chunkIndex,
                             c.contentHash = $contentHash,
                             c.updatedAt = timestamp()
                MERGE (d)-[r:CONTAINS_CHUNK]->(c)
                RETURN c.id AS id
                """;

        neo4jClient.query(chunkCypher)
                .bind(tenantId).to("tenantId")
                .bind(documentId).to("documentId")
                .bind(chunkId).to("chunkId")
                .bind(state.chunkIndex()).to("chunkIndex")
                .bind(state.contentHash()).to("contentHash")
                .run();

        // 2. Wire Extracted Entities
        List<ExtractedEntityDto> entities = state.extractedEntities();
        if (entities != null && !entities.isEmpty()) {
            wireChunkEntities(tenantId, chunkId, entities);
        }
    }

    /**
     * Atomically removes a Chunk node and cleanly detaches its relationships.
     */
    @Transactional
    public void syncChunkDelete(ChunkRowState state) {
        Objects.requireNonNull(state, "ChunkRowState must not be null");
        String tenantId = state.tenantId();
        String chunkId = state.id().toString();

        log.info("Executing Cypher delta delete: chunkId={}, tenantId={}", chunkId, tenantId);

        String deleteCypher = """
                MATCH (c:Chunk {id: $chunkId, tenantId: $tenantId})
                DETACH DELETE c
                """;

        neo4jClient.query(deleteCypher)
                .bind(tenantId).to("tenantId")
                .bind(chunkId).to("chunkId")
                .run();
    }

    private void wireChunkEntities(String tenantId, String chunkId, List<ExtractedEntityDto> entities) {
        String entityCypher = """
                MATCH (c:Chunk {id: $chunkId, tenantId: $tenantId})
                UNWIND $entities AS item
                MERGE (e:Entity {id: item.id, tenantId: $tenantId})
                ON CREATE SET e.name = item.name,
                              e.type = item.type,
                              e.updatedAt = timestamp()
                MERGE (c)-[r:REFERENCES]->(e)
                SET r.confidence = item.confidence
                """;

        List<Map<String, Object>> entityMaps = entities.stream()
                .map(e -> Map.<String, Object>of(
                        "id", e.id(),
                        "name", e.name(),
                        "type", e.type(),
                        "confidence", e.confidence()))
                .toList();

        neo4jClient.query(entityCypher)
                .bind(tenantId).to("tenantId")
                .bind(chunkId).to("chunkId")
                .bind(entityMaps).to("entities")
                .run();
    }
}
```

### 5.4 Two-Tier Hybrid Semantic Cache & Real-Time Invalidation Bus

```java
package com.resonancemachines.context.search;

import com.github.benmanes.caffeine.cache.Cache;
import com.github.benmanes.caffeine.cache.Caffeine;
import io.micrometer.core.instrument.MeterRegistry;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.time.Duration;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;
import java.util.function.Supplier;

/**
 * Two-Tier Hybrid Semantic Cache with targeted chunk-level invalidation.
 * Tier 1: Query Embedding Vector Cache (Normalized Query -> float[])
 * Tier 2: RRF Candidate Fusion Cache ({tenantId}:{workspaceId}:{hash} -> List<SearchResult>)
 */
@Service
public class SemanticCacheManager {

    private static final Logger log = LoggerFactory.getLogger(SemanticCacheManager.class);

    // Tier 1: Dense Query Embedding Cache (eliminates LLM embedding API latency on repeat queries)
    private final Cache<String, float[]> queryEmbeddingCache;

    // Tier 2: RRF Candidate Fusion Cache (stores ranked SearchResults)
    private final Cache<String, List<SearchResult>> rrfCandidateCache;

    // Reverse Index: documentId -> Set<CacheKey> for O(1) granular invalidation
    private final Map<String, Set<String>> documentToCacheKeysIndex = new ConcurrentHashMap<>();

    private final MeterRegistry meterRegistry;

    public SemanticCacheManager(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;

        this.queryEmbeddingCache = Caffeine.newBuilder()
                .maximumSize(5000)
                .expireAfterAccess(Duration.ofHours(2))
                .recordStats()
                .build();

        this.rrfCandidateCache = Caffeine.newBuilder()
                .maximumSize(2000)
                .expireAfterWrite(Duration.ofMinutes(15))
                .recordStats()
                .build();
    }

    /**
     * Tier 1: Retrieves or computes the normalized query embedding vector.
     */
    public float[] getOrComputeQueryEmbedding(String query, Supplier<float[]> embeddingSupplier) {
        String normalizedQuery = normalizeString(query);
        float[] cached = queryEmbeddingCache.getIfPresent(normalizedQuery);
        if (cached != null) {
            meterRegistry.counter("semantic.cache.tier1.hit").increment();
            return cached;
        }

        meterRegistry.counter("semantic.cache.tier1.miss").increment();
        float[] computed = embeddingSupplier.get();
        if (computed != null && computed.length > 0) {
            queryEmbeddingCache.put(normalizedQuery, computed);
        }
        return computed;
    }

    /**
     * Tier 2: Retrieves or computes the fused RRF Search Results.
     */
    public List<SearchResult> getOrExecuteRrfSearch(
            String tenantId,
            String workspaceId,
            String query,
            Supplier<List<SearchResult>> searchSupplier) {

        String cacheKey = buildCacheKey(tenantId, workspaceId, query);
        List<SearchResult> cached = rrfCandidateCache.getIfPresent(cacheKey);

        if (cached != null) {
            log.debug("Tier 2 RRF Cache HIT: key={}", cacheKey);
            meterRegistry.counter("semantic.cache.tier2.hit").increment();
            return cached;
        }

        log.debug("Tier 2 RRF Cache MISS: key={}", cacheKey);
        meterRegistry.counter("semantic.cache.tier2.miss").increment();

        List<SearchResult> freshResults = searchSupplier.get();
        if (freshResults != null && !freshResults.isEmpty()) {
            rrfCandidateCache.put(cacheKey, freshResults);

            // Index reverse dependencies for targeted eviction
            for (SearchResult result : freshResults) {
                String docId = result.getNodeId(); // Associated Document ID
                documentToCacheKeysIndex.computeIfAbsent(docId, k -> ConcurrentHashMap.newKeySet()).add(cacheKey);
            }
        }
        return freshResults;
    }

    /**
     * Event-Driven Granular Eviction: Triggered by Invalidation Bus.
     * Evicts only query results dependent on the mutated document.
     */
    public void invalidateDocument(String tenantId, String documentId) {
        log.info("Invalidating cache for tenantId={}, documentId={}", tenantId, documentId);
        Set<String> affectedKeys = documentToCacheKeysIndex.remove(documentId);

        if (affectedKeys != null && !affectedKeys.isEmpty()) {
            rrfCandidateCache.invalidateAll(affectedKeys);
            meterRegistry.counter("semantic.cache.invalidations", "scope", "document").increment(affectedKeys.size());
            log.info("Evicted {} cached queries associated with documentId={}", affectedKeys.size(), documentId);
        }
    }

    private String buildCacheKey(String tenantId, String workspaceId, String query) {
        String ws = workspaceId != null ? workspaceId : "default";
        String normalizedQuery = normalizeString(query);
        String hash = sha256(normalizedQuery);
        return String.format("%s:%s:%s", tenantId, ws, hash);
    }

    private String normalizeString(String input) {
        return input == null ? "" : input.trim().toLowerCase(Locale.ROOT);
    }

    private String sha256(String input) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hash = digest.digest(input.getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(hash);
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException("SHA-256 not available", e);
        }
    }
}
```

## 6. Failure Modes, Compensations, and Edge Case Analysis

| Failure Scenario | Root Cause | Impact | Automated Architectural Mitigation |
| :--- | :--- | :--- | :--- |
| **1. Neo4j Leader Election or Partition** | Transient network blip between `resonance-unified-context` and Neo4j cluster (`:7687`). | Cypher delta update fails during CDC consumption. | The CDC consumer throws `TransientDataAccessException`; Kafka listener refrains from `acknowledgment.acknowledge()`. | **2. Out-of-Order CDC Event Delivery** | Network rerouting or partition rebalancing causing update $v_2$ to arrive before $v_1$. | Potential regression to stale chunk version. | Chunks carry a monotonic sequence `content_hash` and `updated_at` timestamp. Cypher `SET` statements enforce: `SET c.updatedAt = CASE WHEN timestamp() > c.updatedAt THEN timestamp() ELSE c.updatedAt END`. |
| **3. Malformed Entity Extraction / Poison Pill** | Apache Tika parses corrupted PDF generating malformed Unicode. | Deserialization or indexing failure. | Sealed DTO validation quarantines the event into `resonance.dlq.document_chunks`. The saga coordinator records `PARTIAL_DEGRADED_STATE` in the PostgreSQL `document_registry`, allowing BM25 and vector searches to continue serving existing chunks. |
| **4. Invalidation Bus Network Partition** | Invalidation message dropped or delayed between pods. | Stale cache hit in a specific node's Caffeine memory. | Tier 2 cache enforces a maximum TTL of 15 minutes (`expireAfterWrite(15m)`). Even during catastrophic bus outages, staleness is bounded to $\le 15\text{ minutes}$. |
