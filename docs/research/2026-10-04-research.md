## 1. Executive Summary & Problem Space

The Resonance Platform's **Company Brain** serves as a decentralized cognitive backbone where autonomous AI agent swarms and human knowledge workers collaborate across multi-tenant enterprise organizations (`README.md`, [`ARCHITECTURE.md`](../architecture/ARCHITECTURE.md)). In modern enterprise environments, knowledge does not exist solely as isolated document uploads; it is organized within dynamic, multi-tenant hierarchical file systems composed of structured organizational drives, collaborative team folders, automated agent inbox/outbox pipelines, symlinks across personal workspaces, and external enterprise event streams.

### 1.1 The Virtual File System Hierarchy in the Company Brain
The canonical Virtual File System (VFS) structure required by the platform orchestrates collaborative workflows between humans and autonomous agents:

```
/drive/
├── [Org Alpha]/
│   ├── [Engineering]/
│   │   ├── [inbox]/              <-- Ingestion target for team webhooks, PR diffs, and specs
│   │   ├── [outbox]/             <-- Curated, validated team knowledge artifacts
│   │   ├── specs-v2.pdf          <-- Relational VFS file pointing to CAS MinIO blob
│   │   └── (*Personal Space A)   <-- First-class symlink pointing to /drive/Users/A/
│   └── [Legal]/
│       ├── contracts/
│       └── (*Personal Space B)
└── Users/
    ├── [User A]/
    │   ├── [inbox]/              <-- Raw sensory ingress (meeting audio, YouTube transcripts)
    │   ├── [outbox]/             <-- Processed "Semantic Deltas" produced by personal AI agent
    │   └── (*Engineering Team)   <-- Bidirectional symlink pointing back to /drive/Org Alpha/Engineering
    └── [User B]/
        ├── [inbox]/
        └── [outbox]/
```

### 1.2 Architectural Deficiencies in the Baseline System
Prior to this architectural evolution ([ADR 0001](../adr/0001-transactional-outbox-event-structure.md), [ADR 0002](../adr/0002-core-platform-architecture.md), [ADR 0004](../adr/0004-upload.md), and [ADR 0005](../adr/ADR-0005-event-driven-graphrag-incremental-sync-hybrid-caching.md)):
1. **Disconnected File System & Brain Models:** Binary uploads to MinIO were treated as isolated document blobs. The platform lacked a single authoritative, relational VFS schema tracking organizational folders, personal workspaces, agent inboxes/outboxes, and bidirectional symlinks transactionally.
2. **Double-Buffering & Heap Saturation Risks:** File uploads without strict direct-to-store contracts risk buffering binary payloads in JVM heaps during preprocessing, causing garbage collection (GC) pauses and violating SLA budgets.
3. **Storage Proliferation & Redundant Compute:** When the same asset (e.g., an enterprise policy document) is shared or linked across multiple team workspaces, naive systems store duplicate binaries in MinIO and trigger redundant embedding and graph projection pipelines.
4. **Hierarchical Access Control Drift:** In traditional flat vector stores, permission filtering is coarse-grained (tenant-level only). Agents or users querying knowledge could inadvertently retrieve chunks belonging to restricted subfolders within the same tenant because the vector index possessed no awareness of VFS directory containment or inherited Access Control Lists (ACLs).
5. **Distributed Inconsistency on File Operations:** When an organizational folder is moved, renamed, or deleted, naive synchronous cascading updates across relational schemas, vector databases, and graph databases suffer from the Dual-Write Anti-Pattern and violate **Architectural Invariant 1: No Two-Phase Commit**.

### 2.1 Operational Overhead
- **Event-Driven Push over Polling:** Eliminates all `@Scheduled` database polling routines. Mutations to the VFS hierarchy are captured from the PostgreSQL Write-Ahead Log (WAL) via Debezium Connect (`:8083`) and published to the Redpanda topic `resonance.vfs.events`.
- **Zero Daemon Proliferation:** File uploads leverage MinIO native bucket notifications and direct multipart URL generation, eliminating separate file-watching services, SFTP monitoring daemons, or cron-based directory synchronizers.
- **Zero Cloud-Native Proprietary Lock-In:** The entire stack runs independently of AWS S3 EventBridge, GCP Cloud Functions, or Azure Event Grid. MinIO, PostgreSQL, Redpanda, and Neo4j provide 100% cloud parity on bare metal, private clouds, or commodity Kubernetes.

### 2.2 Scalability Boundaries
- **Zero JVM Heap Buffering:** Binary payloads stream directly from client user agents to MinIO via presigned PUT URLs negotiated with `resonance-upload`. The Spring Boot microservices never load binary streams into heap memory.
- **Content-Addressable Storage (CAS) Deduplication:** Files are indexed in MinIO under their cryptographic digest: `blobs/{sha256_hash}`. Multiple VFS file nodes across personal spaces or team drives point to the identical underlying blob. A single ingestion, Tika extraction, vectorization, and graph linking execution is shared across all references, yielding massive storage and compute savings.
- **Hierarchical Query Complexity:** VFS nodes utilize a dual-representation model:
  1. Relational `parent_id` foreign key with a `materialized_path` column (e.g., `/drive/OrgA/TeamB/inbox/`) indexed via PostgreSQL B-Tree / GIN for $\mathcal{O}(1)$ prefix filtering.
  2. Neo4j directed acyclic graph (DAG) representation with `CONTAINS_NODE` and `SYMLINK_TO` relationships, allowing sub-second recursive subtree expansions without relational recursion overhead.
- **Monotonic Partition Ordering:** Redpanda partitions for `resonance.vfs.events` are keyed on `hash(tenant_id, org_id)`, ensuring that all hierarchical mutations within an organizational boundary execute in strict causal sequence without distributed locks.

### 2.3 Multi-Tenancy Isolation
- **PostgreSQL Row-Level Security (RLS):** All VFS tables (`vfs_nodes`, `vfs_blobs`, `vfs_entitlements`, `outbox_events`) enforce RLS policies bound to the database session variable `app.current_tenant_id`:
  ```sql
  ALTER TABLE vfs_nodes ENABLE ROW LEVEL SECURITY;
  CREATE POLICY vfs_tenant_isolation ON vfs_nodes
      USING (tenant_id = current_setting('app.current_tenant_id', true));
  ```
- **Neo4j Cypher Scoping:** Every Neo4j node (`VfsNode`, `Document`, `Person`, `Company`) carries an indexed `tenantId` property. All Cypher queries bind `$tenantId` as a prepared parameter; dynamic label interpolation is strictly prohibited:
  ```cypher
  MATCH (t:Tenant {id: $tenantId})-[:OWNS_WORKSPACE]->(w:Workspace {id: $workspaceId})
  MATCH (w)-[:ROOT_VFS_NODE]->(root:VfsFolder)
  MATCH path = (root)-[:CONTAINS_NODE*0..10]->(target:VfsNode {tenantId: $tenantId})
  RETURN target;
  ```
- **MinIO Storage Partitioning:** Object keys strictly isolate tenant namespaces:
  `resonance-uploads/{tenantId}/{orgId}/blobs/{sha256}`. MinIO STS (Security Token Service) presigned URLs restrict client PUT/GET operations exclusively to tenant-authorized object keys.
- **ABAC/RBAC Path Policy Enforcement:** In `resonance-entitlement`, every file operation evaluates the user's role and team memberships against the materialized VFS path, preventing unauthorized traversal through symlinks.

### 2.4 Developer Velocity
- **Strict Java 21 LTS Type Safety:** Domain events, commands, and VFS tree models are modeled using Java 21 `sealed interface` and `record` primitives, providing exhaustive pattern matching at compile time.
- **Contract-First Event Schemas:** Redpanda Schema Registry enforces `BACKWARD_TRANSITIVE` evolution for all VFS events, ensuring backward-compatible schema updates between front-office producers and back-office consumers.
- **Unified Starter Ecosystem:** Developers utilize `resonance-starter-core`, `resonance-starter-frontoffice`, and `resonance-starter-middleoffice` to inherit pre-configured transactional outbox publishers, MinIO client abstractions, and security interceptors without boilerplate configuration.

### 3.1 Front-Office Tier: Outbox Pattern & Zero-Heap Ingestion

#### 1. Multipart Direct-to-MinIO Negotiation (`resonance-upload` `:8008`)
- The client (human UI or AI agent) issues `POST /api/v1/upload/multipart` with metadata (`filename`, `mimeType`, `expectedSize`, `tenantId`, `orgId`, `vfsParentId`).
- `resonance-upload` computes the target Content-Addressable Storage (CAS) key prefix:
  `${tenantId}/${orgId}/sessions/${sessionId}/${filename}`.
- It registers an upload session in PostgreSQL and returns presigned MinIO S3 multipart URLs for each chunk (e.g., 5 MB parts).
- **Zero JVM Heap Saturation:** The client streams chunks directly into MinIO (`:9000`) over HTTPS. The microservice CPU and heap memory are entirely unburdened by binary data transfer.

#### 2. Atomic Completion & Transactional Outbox
- When all parts are uploaded, the client calls `POST /api/v1/upload/complete` containing part ETags and the overall file SHA-256 digest.
- `resonance-upload` instructs MinIO to assemble the multipart object, verifies the computed SHA-256 against MinIO's checksum, and updates its local PostgreSQL database:
  - Links the file to the target VFS parent folder.
  - Inserts a `FilePayloadUploadedEvent` into `outbox_events` in the **exact same database transaction**.
- Debezium Connect monitors the PostgreSQL WAL and streams the event to the Redpanda topic `resonance.vfs.events`.

#### 3. VFS Hierarchy Mutation Commands (`resonance-action` `:8001`)
- Standard file-system operations (`CREATE_FOLDER`, `MOVE_NODE`, `RENAME_NODE`, `CREATE_SYMLINK`, `DELETE_NODE`) are submitted to `resonance-action`.
- The gateway verifies tenant authorization, creates or updates the corresponding `vfs_nodes` row, and writes a corresponding `VfsNodeMutationEvent` to `outbox_events`.
- No distributed locks are acquired. Causal consistency is guaranteed by partitioning Redpanda topics by `hash(tenantId, orgId)`.

### 3.2 Middle-Office Tier: Choreographed Sagas & Governance

The file system ingestion and restructuring lifecycle is managed by **Choreographed Sagas** coordinated by `resonance-workflow` (`:8108`) without Two-Phase Commit:

```
[FilePayloadUploadedEvent]
           │
           ▼
[Step 1: Quota & Entitlement Validation] ──(Quota Exceeded)──▶ [Compensating Tx: Purge MinIO & Emit Failed]
           │ (Approved)
           ▼
[Step 2: Streaming Metadata & Text Extraction] (resonance-meta :8109 - Apache Tika)
           │
           ▼
[Step 3: Edge PII Tokenization] (resonance-crypto :8103 - AES-256-GCM Vault)
           │
           ▼
[Step 4: Vectorization & Content Deduplication] (PostgreSQL pgvector / tsvector)
           │
           ▼
[Step 5: Neo4j VFS Hierarchy & Knowledge Graph Projection] (resonance-unified-context :9001)
           │
           ▼
[Step 6: Saga Completed Event] ──▶ Update VFS Node State to ACTIVE
```

#### 1. Streaming Metadata Extraction (`resonance-meta` `:8109`)
- Rather than downloading files to local disk, `resonance-meta` opens an S3 streaming `InputStream` from MinIO via HTTP chunked transfer.
- Apache Tika streams the binary content through `AutoDetectParser`, generating text chunks, MIME metadata, document outline trees, and Schema.org semantic metadata.
- Local disk spooling is completely avoided, eliminating container ephemeral storage exhaustion.

#### 2. Edge PII Tokenization (`resonance-crypto` `:8103`)
- Extracted text streams through `resonance-crypto`.
- Sensitive entities (PII, PCI, secrets) are detected via regular expression engines and named entity models, replaced with deterministic surrogate UUID tokens (e.g., `pii_tok_7f9a8b...`), and recorded in the isolated PostgreSQL crypto-vault.
- Zero plaintext PII enters the Redpanda event bus, PostgreSQL vector tables, or Neo4j knowledge graph.

#### 3. Reversible Compensating Transactions
If any stage in the saga fails (e.g., Tika decompression bomb detected, quota exceeded in `resonance-billing`, or schema validation failure):
- `resonance-workflow` transitions the saga state machine to `COMPENSATING`.
- Emits `VfsIngestionFailedEvent` to Redpanda.
- **Compensating Actions Executed:**
  1. `resonance-upload` issues an asynchronous S3 delete command to MinIO to remove orphan binary objects.
  2. `resonance-action` marks the `vfs_nodes` record with status `QUARANTINED` or deletes the pending node.
  3. `resonance-support` (`:8006`) captures the incident in the Dead-Letter Queue (DLQ) for Human-In-The-Loop (HITL) review.

#### 1. The Symlink Tree Pattern for AI Agent Workspaces
In alignment with the target VFS specification:
- Every user/agent possesses an isolated **Personal Space** containing dedicated `[inbox]` and `[outbox]` folders.
- Teams contain first-class `symlink` nodes pointing to member personal spaces.
- Personal spaces contain reverse symlinks pointing to assigned teams.
- **Agent Workflow Routing:**
  1. An external webhook (e.g., YouTube transcript, meeting audio) injects raw payloads into `/drive/Users/A/[inbox]/source/`.
  2. The personal agent processes the document and outputs normalized Knowledge Graph nodes (the "Semantic Delta") into `/drive/Users/A/[outbox]/`.
  3. Supervisory team agents traverse the team symlink (`(*Personal Space A) -> /drive/Users/A`) into the outbox to merge validated insights into the team's shared knowledge graph.

#### 2. Path-Scoped Hybrid GraphRAG Query Routing
When a query arrives at `resonance-research` (`:8005`) with an optional `vfsPath` or `vfsNodeId` parameter:
1. **VFS Subtree Expansion:** `resonance-unified-context` performs an index-assisted Cypher traversal starting from the scoped VFS node, recursively gathering all descendant `Document` IDs within the permitted depth (including single-hop symlinks):
   ```cypher
   MATCH (root:VfsNode {id: $vfsNodeId, tenantId: $tenantId})
   OPTIONAL MATCH (root)-[:CONTAINS_NODE|SYMLINK_TO*0..10]->(d:Document {tenantId: $tenantId})
   RETURN collect(DISTINCT d.id) AS allowedDocumentIds;
   ```
2. **Constrained Parallel Retrieval:**
   - **Dense Vector Search:** PostgreSQL `pgvector` filters candidates using an SQL `WHERE document_id = ANY(:allowedDocumentIds)` clause, evaluating cosine similarity in $\le 380\text{ ms}$.
   - **Lexical Search:** PostgreSQL `tsvector` runs BM25 matching constrained by the same document subset in $\le 120\text{ ms}$.
   - **Multi-Hop Graph Traversal:** Neo4j traverses entity relationships anchored strictly to the allowed documents in $\le 320\text{ ms}$.
3. **Reciprocal Rank Fusion (RRF):** Blends the scores into a unified candidate ranking in $\le 45\text{ ms}$.
4. **Synthesis:** Gemini LLM synthesizes ground-truth context in $\le 1700\text{ ms}$.

## 5. Architectural Patterns: CQRS, Sagas & Idempotent Consumers

### 5.1 Command Query Responsibility Segregation (CQRS)
To prevent lock contention on the relational VFS tree during heavy multi-agent write operations:
- **Write Side (Commands):** Handled exclusively by `resonance-action` (`:8001`) and `resonance-upload` (`:8008`). Mutations are written to PostgreSQL `vfs_nodes` with Row-Level Security, emitting `VfsEvent` payloads through the Transactional Outbox.
- **Read Side (Queries):** Handled by `resonance-research` (`:8005`) querying read-optimized materialized paths in PostgreSQL and recursive graph projections in Neo4j 5.20.

### 5.2 Choreographed Saga with Reverse Compensation
Rather than distributed 2PC locking, every multi-service operation (file upload, virus scanning, PII redaction, vectorization, and knowledge graph ingestion) is broken down into autonomous compensating steps. If an unrecoverable failure occurs at any intermediate step, reverse compensating events (`CompensateSagaMessage`) roll back the uploaded MinIO binary and tombstone the relational VFS node.

### 5.3 Idempotent Consumers with Multi-Tier Deduplication
In high-throughput event streaming over Redpanda, network blips and rebalances cause at-least-once message re-delivery. Every consumer microservice enforces idempotency using a two-tier strategy:
1. **Tier 1 (Fast-Path In-Memory Cache):** A local Caffeine cache (`maximumSize = 50,000`, `expireAfterWrite = 10m`) keys on `messageId`. If present, the message is acknowledged immediately.
2. **Tier 2 (Authoritative Relational Ledger):** An atomic PostgreSQL `processed_messages` ledger with unique constraint `(tenant_id, message_id)`. The business transaction and message recording commit in the same local database transaction.

### 6.3 Front-Office Command Gateway: Transactional Outbox Pattern

```java
package com.resonancemachines.resonanceaction.vfs.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.resonancemachines.core.outbox.OutboxEventEntity;
import com.resonancemachines.core.outbox.OutboxEventRepository;
import com.resonancemachines.core.vfs.domain.VfsNodeEntity;
import com.resonancemachines.core.vfs.domain.VfsNodeStatus;
import com.resonancemachines.core.vfs.domain.VfsNodeType;
import com.resonancemachines.core.vfs.event.VfsEvent;
import com.resonancemachines.resonanceaction.vfs.repository.VfsNodeRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;
import java.util.UUID;

/**
 * Command Gateway service executing VFS operations with Transactional Outbox guarantees.
 * All mutations write the entity state and the outbox event in the same atomic SQL transaction.
 */
@Service
public class VfsCommandService {

    private final VfsNodeRepository vfsNodeRepository;
    private final OutboxEventRepository outboxEventRepository;
    private final ObjectMapper objectMapper;

    public VfsCommandService(
            VfsNodeRepository vfsNodeRepository,
            OutboxEventRepository outboxEventRepository,
            ObjectMapper objectMapper) {
        this.vfsNodeRepository = vfsNodeRepository;
        this.outboxEventRepository = outboxEventRepository;
        this.objectMapper = objectMapper;
    }

    public record CreateFolderCommand(
            String tenantId,
            String orgId,
            String userId,
            String folderName,
            UUID parentFolderId
    ) {}

    public record MoveNodeCommand(
            String tenantId,
            String orgId,
            String userId,
            UUID nodeId,
            UUID newParentFolderId
    ) {}

    @Transactional
    public VfsNodeEntity createFolder(CreateFolderCommand cmd) {
        VfsNodeEntity parent = cmd.parentFolderId() != null
                ? vfsNodeRepository.findById(cmd.parentFolderId())
                        .orElseThrow(() -> new IllegalArgumentException("Parent folder not found: " + cmd.parentFolderId()))
                : null;

        String parentPath = parent != null ? parent.getMaterializedPath() : "/drive/" + cmd.orgId();
        String currentPath = parentPath + "/" + cmd.folderName() + "/";

        UUID nodeId = UUID.randomUUID();
        VfsNodeEntity entity = new VfsNodeEntity(
                nodeId,
                cmd.tenantId(),
                cmd.orgId(),
                cmd.userId(),
                cmd.folderName(),
                VfsNodeType.FOLDER,
                cmd.parentFolderId(),
                null,
                currentPath,
                null,
                null,
                0L,
                VfsNodeStatus.ACTIVE
        );

        VfsNodeEntity saved = vfsNodeRepository.save(entity);

        VfsEvent.NodeCreated event = new VfsEvent.NodeCreated(
                UUID.randomUUID(),
                cmd.tenantId(),
                cmd.orgId(),
                saved.getId(),
                saved.getName(),
                VfsNodeType.FOLDER,
                cmd.parentFolderId(),
                saved.getMaterializedPath(),
                Instant.now()
        );

        emitOutboxEvent(cmd.tenantId(), cmd.orgId(), "VfsNode", saved.getId().toString(), event);
        return saved;
    }

    @Transactional
    public VfsNodeEntity moveNode(MoveNodeCommand cmd) {
        VfsNodeEntity targetNode = vfsNodeRepository.findById(cmd.nodeId())
                .orElseThrow(() -> new IllegalArgumentException("Node not found: " + cmd.nodeId()));

        VfsNodeEntity newParent = vfsNodeRepository.findById(cmd.newParentFolderId())
                .orElseThrow(() -> new IllegalArgumentException("New parent folder not found: " + cmd.newParentFolderId()));

        UUID oldParentId = targetNode.getParentId();
        String oldPath = targetNode.getMaterializedPath();
        String newPath = newParent.getMaterializedPath() + targetNode.getName()
                + (targetNode.getType() == VfsNodeType.FOLDER ? "/" : "");

        targetNode.setParentId(newParent.getId());
        targetNode.setMaterializedPath(newPath);
        VfsNodeEntity updated = vfsNodeRepository.save(targetNode);

        VfsEvent.NodeMoved event = new VfsEvent.NodeMoved(
                UUID.randomUUID(),
                cmd.tenantId(),
                cmd.orgId(),
                updated.getId(),
                oldParentId,
                newParent.getId(),
                oldPath,
                newPath,
                Instant.now()
        );

        emitOutboxEvent(cmd.tenantId(), cmd.orgId(), "VfsNode", updated.getId().toString(), event);
        return updated;
    }

    private void emitOutboxEvent(String tenantId, String orgId, String aggregateType, String aggregateId, VfsEvent event) {
        try {
            String payloadJson = objectMapper.writeValueAsString(event);
            OutboxEventEntity outboxRecord = new OutboxEventEntity(
                    UUID.randomUUID(),
                    tenantId,
                    aggregateType,
                    aggregateId,
                    "resonance.vfs.events",
                    tenantId + ":" + orgId, // Partition key guaranteeing monotonic causal order
                    payloadJson,
                    Instant.now()
            );
            outboxEventRepository.save(outboxRecord);
        } catch (Exception e) {
            throw new IllegalStateException("Failed to serialize VFS domain event for outbox", e);
        }
    }
}
```

```java
package com.resonancemachines.resonanceworkflow.vfs.saga;

import com.resonancemachines.core.vfs.event.VfsEvent;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.core.KafkaTemplate;
import org.springframework.stereotype.Service;

import java.util.Objects;
import java.util.UUID;

/**
 * Choreographed Saga Coordinator for file ingestion and restructuring workflows.
 * Coordinates streaming Tika extraction, PII tokenization, vectorization, and reverse compensation.
 */
@Service
public class VfsIngestionSagaCoordinator {

    private static final Logger log = LoggerFactory.getLogger(VfsIngestionSagaCoordinator.class);

    private final KafkaTemplate<String, Object> kafkaTemplate;

    public VfsIngestionSagaCoordinator(KafkaTemplate<String, Object> kafkaTemplate) {
        this.kafkaTemplate = kafkaTemplate;
    }

    public record IngestionSagaContext(
            UUID sagaId,
            String tenantId,
            String orgId,
            UUID nodeId,
            String blobSha256,
            String mimeType
    ) {}

    public record CompensateSagaMessage(
            UUID sagaId,
            String tenantId,
            String orgId,
            UUID nodeId,
            String blobSha256,
            String failureReason
    ) {}

    @KafkaListener(topics = "resonance.vfs.events", groupId = "resonance-workflow-saga-group")
    public void onVfsEvent(VfsEvent event) {
        switch (event) {
            case VfsEvent.FileIngested fileIngested -> handleFileIngested(fileIngested);
            case VfsEvent.NodeMoved nodeMoved -> handleNodeMoved(nodeMoved);
            case VfsEvent.NodeDeleted nodeDeleted -> handleNodeDeleted(nodeDeleted);
            case VfsEvent.NodeCreated created -> log.info("Node created: {}", created.nodeId());
            case VfsEvent.NodeRenamed renamed -> log.info("Node renamed: {}", renamed.nodeId());
            case VfsEvent.SymlinkCreated symlink -> log.info("Symlink created: {}", symlink.symlinkNodeId());
        }
    }

    private void handleFileIngested(VfsEvent.FileIngested event) {
        UUID sagaId = UUID.randomUUID();
        log.info("[SAGA {}] Initiating File Ingestion Saga for node={}", sagaId, event.nodeId());

        try {
            // Step 1: Trigger Streaming Extraction in resonance-meta (:8109)
            kafkaTemplate.send("resonance.meta.extract-command", event.tenantId(),
                    new IngestionSagaContext(
                            sagaId,
                            event.tenantId(),
                            event.orgId(),
                            event.nodeId(),
                            event.blobSha256(),
                            event.mimeType()
                    ));
        } catch (Exception ex) {
            log.error("[SAGA {}] Ingestion initiation failed. Triggering reverse compensation", sagaId, ex);
            compensateIngestionFailure(sagaId, event.tenantId(), event.orgId(), event.nodeId(), event.blobSha256(), ex.getMessage());
        }
    }

    private void handleNodeMoved(VfsEvent.NodeMoved event) {
        log.info("Propagating VFS restructure to Neo4j Graph Cosmos: node={}, newPath={}",
                event.nodeId(), event.newMaterializedPath());
        kafkaTemplate.send("resonance.unifiedcontext.vfs-sync", event.tenantId(), event);
    }

    private void handleNodeDeleted(VfsEvent.NodeDeleted event) {
        log.info("Propagating VFS deletion to Neo4j Graph Cosmos: node={}", event.nodeId());
        kafkaTemplate.send("resonance.unifiedcontext.vfs-sync", event.tenantId(), event);
    }

    public void compensateIngestionFailure(
            UUID sagaId,
            String tenantId,
            String orgId,
            UUID nodeId,
            String blobSha256,
            String reason) {
        log.warn("[SAGA {}] Executing Reverse Compensating Transaction: tenant={}, node={}, reason={}",
                sagaId, tenantId, nodeId, reason);

        CompensateSagaMessage compMsg = new CompensateSagaMessage(
                sagaId,
                tenantId,
                orgId,
                nodeId,
                blobSha256,
                reason
        );

        // 1. Instruct MinIO upload service to purge orphan binary chunks
        kafkaTemplate.send("resonance.upload.compensation", tenantId, compMsg);

        // 2. Instruct Action service to tombstone/quarantine the VFS node
        kafkaTemplate.send("resonance.action.quarantine-node", tenantId, compMsg);

        // 3. Dispatch poison-pill incident notification to resonance-support (:8006)
        kafkaTemplate.send("resonance.support.dlq-incident", tenantId, compMsg);
    }
}
```

```java
import java.time.Duration;

/**
 * Two-tier idempotent message consumer engine.
 * Fast-path Caffeine in-memory cache + Authoritative PostgreSQL processed_messages ledger.
 */
@Component
public class MessageDeduplicationLedger {

    private static final Logger log = LoggerFactory.getLogger(MessageDeduplicationLedger.class);

    private final EntityManager entityManager;

    private final Cache<String, Boolean> fastPathCache = Caffeine.newBuilder()
            .maximumSize(50_000)
            .expireAfterWrite(Duration.ofMinutes(10))
            .build();

    public MessageDeduplicationLedger(EntityManager entityManager) {
        this.entityManager = entityManager;
    }

    @Entity
    @Table(
        name = "processed_messages",
        uniqueConstraints = @UniqueConstraint(name = "uq_tenant_message", columnNames = {"tenant_id", "message_id"})
    )
    public static class ProcessedMessageEntity {
        @Id
        @Column(name = "id")
        private UUID id;

        @Column(name = "tenant_id", nullable = false)
        private String tenantId;

        @Column(name = "message_id", nullable = false)
        private String messageId;

        @Column(name = "consumer_group", nullable = false)
        private String consumerGroup;

        @Column(name = "processed_at", nullable = false)
        private Instant processedAt;

        public ProcessedMessageEntity() {}

        public ProcessedMessageEntity(UUID id, String tenantId, String messageId, String consumerGroup, Instant processedAt) {
            this.id = id;
            this.tenantId = tenantId;
            this.messageId = messageId;
            this.consumerGroup = consumerGroup;
            this.processedAt = processedAt;
        }
    }

    /**
     * Checks idempotency and atomically records the processed message in the database.
     * Returns true if already processed, false if this is the first execution.
     */
    @Transactional(propagation = Propagation.REQUIRED)
    public boolean isDuplicateAndRecord(String tenantId, String messageId, String consumerGroup) {
        String cacheKey = tenantId + ":" + messageId;
        if (Boolean.TRUE.equals(fastPathCache.getIfPresent(cacheKey))) {
            log.debug("Deduplication Fast-Path Cache Hit: key={}", cacheKey);
            return true;
        }

        try {
            ProcessedMessageEntity entity = new ProcessedMessageEntity(
                    UUID.randomUUID(),
                    tenantId,
                    messageId,
                    consumerGroup,
                    Instant.now()
            );
            entityManager.persist(entity);
            entityManager.flush();
            fastPathCache.put(cacheKey, Boolean.TRUE);
            return false;
        } catch (PersistenceException ex) {
            log.warn("Deduplication Relational Unique Key Conflict: key={}", cacheKey);
            fastPathCache.put(cacheKey, Boolean.TRUE);
            return true;
        }
    }
}
```

### 6.6 Platform Brain Neo4j Graph Cosmos & Subtree Cypher Projector

```java
package com.resonancemachines.resonanceunifiedcontext.vfs.service;

import com.resonancemachines.core.vfs.event.VfsEvent;
import org.neo4j.cypherdsl.core.Cypher;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.data.neo4j.core.Neo4jClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.Map;
import java.util.Objects;
import java.util.UUID;

/**
 * Projects Virtual File System structures into the Neo4j Graph Cosmos.
 * Maintains structural CONTAINS_NODE and SYMLINK_TO relationships with strict $tenantId scoping.
 */
@Service
public class Neo4jVfsGraphService {

    private static final Logger log = LoggerFactory.getLogger(Neo4jVfsGraphService.class);

    private final Neo4jClient neo4jClient;

    public Neo4jVfsGraphService(Neo4jClient neo4jClient) {
        this.neo4jClient = neo4jClient;
    }

    @Transactional
    public void projectVfsNodeCreated(VfsEvent.NodeCreated event) {
        log.info("[Neo4j] Projecting VFS node: id={}, path={}", event.nodeId(), event.materializedPath());

        String cypher = """
                MERGE (t:Tenant {id: $tenantId})
                MERGE (node:VfsNode {id: $nodeId, tenantId: $tenantId})
                SET node.name = $name,
                    node.type = $type,
                    node.materializedPath = $path,
                    node.updatedAt = datetime()
                WITH t, node
                MATCH (p:VfsNode {id: $parentId, tenantId: $tenantId})
                MERGE (p)-[:CONTAINS_NODE]->(node)
                """;

        neo4jClient.query(cypher)
                .bind(event.tenantId()).to("tenantId")
                .bind(event.nodeId().toString()).to("nodeId")
                .bind(event.name()).to("name")
                .bind(event.type().name()).to("type")
                .bind(event.materializedPath()).to("path")
                .bind(event.parentId() != null ? event.parentId().toString() : "ROOT").to("parentId")
                .run();
    }

    @Transactional
    public void projectVfsSymlink(VfsEvent.SymlinkCreated event) {
        log.info("[Neo4j] Projecting VFS Symlink: symlinkId={}, targetId={}",
                event.symlinkNodeId(), event.targetNodeId());

        String cypher = """
                MATCH (s:VfsNode {id: $symlinkId, tenantId: $tenantId})
                MATCH (target:VfsNode {id: $targetId, tenantId: $tenantId})
                MERGE (s)-[:SYMLINK_TO]->(target)
                """;

        neo4jClient.query(cypher)
                .bind(event.tenantId()).to("tenantId")
                .bind(event.symlinkNodeId().toString()).to("symlinkId")
                .bind(event.targetNodeId().toString()).to("targetId")
                .run();
    }

    @Transactional
    public void projectVfsNodeMoved(VfsEvent.NodeMoved event) {
        log.info("[Neo4j] Re-parenting VFS node: id={}, newParentId={}",
                event.nodeId(), event.newParentId());

        String cypher = """
                MATCH (node:VfsNode {id: $nodeId, tenantId: $tenantId})
                OPTIONAL MATCH (oldParent:VfsNode)-[oldRel:CONTAINS_NODE]->(node)
                DELETE oldRel
                WITH node
                MATCH (newParent:VfsNode {id: $newParentId, tenantId: $tenantId})
                MERGE (newParent)-[:CONTAINS_NODE]->(node)
                SET node.materializedPath = $newPath
                """;

        neo4jClient.query(cypher)
                .bind(event.tenantId()).to("tenantId")
                .bind(event.nodeId().toString()).to("nodeId")
                .bind(event.newParentId().toString()).to("newParentId")
                .bind(event.newMaterializedPath()).to("newPath")
                .run();
    }

    /**
     * Resolves all descendant Document IDs within a VFS subtree.
     * Evaluates CONTAINS_NODE and SYMLINK_TO relationships up to maxDepth.
     */
    public List<String> resolveDescendantDocumentIds(String tenantId, UUID vfsNodeId, int maxDepth) {
        Objects.requireNonNull(tenantId, "tenantId must not be null");
        Objects.requireNonNull(vfsNodeId, "vfsNodeId must not be null");
        int safeDepth = Math.min(Math.max(maxDepth, 1), 10);

        String cypher = String.format("""
                MATCH (root:VfsNode {id: $rootId, tenantId: $tenantId})
                CALL apoc.path.subgraphNodes(root, {
                    relationshipFilter: 'CONTAINS_NODE>|SYMLINK_TO>',
                    maxLevel: %d,
                    bfs: true
                }) YIELD node
                WHERE node:Document OR node.type = 'FILE'
                RETURN DISTINCT node.id AS docId
                """, safeDepth);

        return neo4jClient.query(cypher)
                .bind(vfsNodeId.toString()).to("rootId")
                .bind(tenantId).to("tenantId")
                .fetchAs(String.class)
                .mappedBy((typeSystem, record) -> record.get("docId").asString())
                .all()
                .stream()
                .toList();
    }
}
```

### 6.7 Path-Scoped Hybrid GraphRAG Query Façade

```java
package com.resonancemachines.resonanceresearch.vfs.service;

import com.resonancemachines.resonanceunifiedcontext.vfs.service.Neo4jVfsGraphService;
import org.springframework.ai.chat.model.ChatModel;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;

import java.util.*;

/**
 * Natural language retrieval façade executing path-scoped GraphRAG queries.
 * Combines Neo4j subtree resolution, pgvector cosine search, tsvector lexical search,
 * Reciprocal Rank Fusion (RRF), and grounded LLM generation within the <= 4.0s SLA.
 */
@Service
public class PathScopedGraphRagService {

    private final Neo4jVfsGraphService neo4jVfsGraphService;
    private final JdbcClient jdbcClient;
    private final ChatModel chatModel;

    public PathScopedGraphRagService(
            Neo4jVfsGraphService neo4jVfsGraphService,
            JdbcClient jdbcClient,
            ChatModel chatModel) {
        this.neo4jVfsGraphService = neo4jVfsGraphService;
        this.jdbcClient = jdbcClient;
        this.chatModel = chatModel;
    }

    public record ScopedQueryRequest(
            String tenantId,
            String userId,
            String queryText,
            UUID vfsScopeFolderId,
            int maxResults
    ) {}

    public record GroundedAnswerResponse(
            String answer,
            List<String> citedDocumentIds,
            long executionTimeMs
    ) {}

    public GroundedAnswerResponse executeScopedQuery(ScopedQueryRequest request) {
        long startTime = System.currentTimeMillis();

        // Step 1: Pre-filter Document Candidates via Neo4j Subtree Expansion (<= 40ms)
        List<String> allowedDocIds = Collections.emptyList();
        if (request.vfsScopeFolderId() != null) {
            allowedDocIds = neo4jVfsGraphService.resolveDescendantDocumentIds(
                    request.tenantId(),
                    request.vfsScopeFolderId(),
                    8
            );
            if (allowedDocIds.isEmpty()) {
                return new GroundedAnswerResponse(
                        "No documents found within the selected folder scope.",
                        List.of(),
                        System.currentTimeMillis() - startTime
                );
            }
        }

        // Step 2: Constrained Dense Vector & BM25 Retrieval via PostgreSQL pgvector (<= 380ms)
        List<String> retrievedChunks = retrieveConstrainedChunks(
                request.tenantId(),
                request.queryText(),
                allowedDocIds,
                request.maxResults()
        );

        // Step 3: Grounded Context Synthesis via Gemini LLM (<= 1700ms)
        String promptText = """
                You are the Resonance Company Brain knowledge assistant.
                Answer the user query strictly using the following retrieved document context.
                If the context does not contain sufficient information, state that clearly.
                
                Retrieved Context:
                %s
                
                Query: %s
                """.formatted(String.join("\n---\n", retrievedChunks), request.queryText());

        String generatedAnswer = chatModel.call(new Prompt(promptText))
                .getResult()
                .getOutput()
                .getText();

        long totalDuration = System.currentTimeMillis() - startTime;
        return new GroundedAnswerResponse(generatedAnswer, allowedDocIds, totalDuration);
    }

    private List<String> retrieveConstrainedChunks(
            String tenantId,
            String queryText,
            List<String> allowedDocIds,
            int limit) {

        if (allowedDocIds.isEmpty()) {
            return jdbcClient.sql("""
                    SELECT chunk_content
                    FROM document_chunks
                    WHERE tenant_id = :tenantId
                    ORDER BY embedding <=> ai_embedding_generate(:query)
                    LIMIT :limit
                    """)
                    .param("tenantId", tenantId)
                    .param("query", queryText)
                    .param("limit", limit)
                    .query(String.class)
                    .list();
        } else {
            return jdbcClient.sql("""
                    SELECT chunk_content
                    FROM document_chunks
                    WHERE tenant_id = :tenantId
                      AND document_id = ANY(:docIds::text[])
                    ORDER BY embedding <=> ai_embedding_generate(:query)
                    LIMIT :limit
                    """)
                    .param("tenantId", tenantId)
                    .param("docIds", allowedDocIds.toArray(new String[0]))
                    .param("query", queryText)
                    .param("limit", limit)
                    .query(String.class)
                    .list();
        }
    }
}
```

### 6.8 Middle-Office Policy Enforcement Point: VFS Path Entitlement Evaluator

```java
package com.resonancemachines.resonanceentitlement.vfs.service;

import com.resonancemachines.resonanceentitlement.entity.FileEntitlement;
import com.resonancemachines.resonanceentitlement.repository.FileEntitlementRepository;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.cache.annotation.Cacheable;
import org.springframework.stereotype.Service;

import java.util.Objects;

/**
 * Attribute-Based Access Control (ABAC) engine for Virtual File System operations.
 * Evaluates path hierarchy, role permissions, and tenant isolation before file access.
 */
@Service
public class VfsEntitlementService {

    private static final Logger log = LoggerFactory.getLogger(VfsEntitlementService.class);

    private final FileEntitlementRepository entitlementRepository;

    public VfsEntitlementService(FileEntitlementRepository entitlementRepository) {
        this.entitlementRepository = entitlementRepository;
    }

    public record AccessEvaluationRequest(
            String tenantId,
            String userId,
            String vfsPath,
            String action // "READ", "WRITE", "DELETE", "SHARE"
    ) {}

    public record AccessDecision(
            boolean granted,
            String reason
    ) {}

    /**
     * Evaluates access with Caffeine cache memoization.
     */
    @Cacheable(
            value = "vfs-entitlements",
            key = "{#request.tenantId(), #request.userId(), #request.vfsPath(), #request.action()}"
    )
    public AccessDecision evaluateAccess(AccessEvaluationRequest request) {
        Objects.requireNonNull(request, "AccessEvaluationRequest must not be null");

        log.debug("[ABAC] Evaluating access: user={}, path={}, action={}",
                request.userId(), request.vfsPath(), request.action());

        // Rule 1: Root Tenant Boundary Isolation
        if (request.tenantId() == null || request.tenantId().isBlank()) {
            return new AccessDecision(false, "DENY: Missing tenant identifier");
        }

        // Rule 2: Personal Space Isolation (/drive/Users/{userId}/...)
        if (request.vfsPath().startsWith("/drive/Users/")) {
            String[] parts = request.vfsPath().split("/");
            if (parts.length >= 4) {
                String targetUserId = parts[3];
                // Personal spaces allow write/delete only to owner
                if (!targetUserId.equals(request.userId()) && !"READ".equalsIgnoreCase(request.action())) {
                    return new AccessDecision(false, "DENY: Cannot mutate foreign personal space");
                }
            }
        }

        // Rule 3: Database Policy Lookup
        boolean isExplicitlyDenied = entitlementRepository.existsByUserIdAndTenantIdAndResourceTypeAndActionAndGrantedFalse(
                request.userId(), request.tenantId(), request.vfsPath(), request.action()
        );

        if (isExplicitlyDenied) {
            return new AccessDecision(false, "DENY: Explicit negative entitlement rule");
        }

        return new AccessDecision(true, "PERMIT: Standard workspace policy granted");
    }
}
```

## 7. Security Invariants, Failure Modes & Poison Pill Quarantine

### 7.1 Compliance with Platform Invariants

| Invariant | System Enforcement Mechanism | Failure Defense |
| :--- | :--- | :--- |
| **1. No Two-Phase Commit** | Ingestion, restructure, and deletion execute via Choreographed Sagas and Outbox patterns over Redpanda. | Failures invoke reversible compensating transactions (S3 object purge, node tombstoning). |
| **2. Zero Plaintext PII in Mesh** | `resonance-crypto` intercepts text streams before vectorization and graph extraction, replacing entities with AES-256-GCM tokens. | If tokenization fails, the saga halts immediately; plaintext is never published to event topics. |
| **3. Database-Per-Service** | VFS metadata resides in `resonance-action`, saga state in `resonance-workflow`, vector/graph state in `resonance-unified-context`. | Communication occurs exclusively over Redpanda topics and gRPC Protobuf contracts; no cross-DB SQL joins. |
| **4. Multi-Tenant Isolation** | PostgreSQL kernel RLS, Neo4j `$tenantId` parameters, and MinIO `${tenantId}/` bucket prefixes mathematically enforce tenant boundaries. | All queries fail-closed if tenant context is missing. |
| **5. Deterministic Classpaths** | All versions managed centrally in `resonance-bom`. | Zero explicit `<version>` tags in child Maven POMs. |

### 7.2 Poison Pill & Quarantine Isolation
If an uploaded file contains malicious macros, a decompression bomb (ZIP bomb), or causes Tika parser crashes:
1. `resonance-meta` intercepts the parser exception and marks the task failed.
2. `resonance-workflow` transitions the saga to `QUARANTINE`.
3. The binary in MinIO is tagged with `X-Resonance-Quarantine: true` and moved to a non-public quarantine prefix.
4. An incident ticket is emitted to `resonance-support` (`:8006`) with the correlation ID, preventing infinite consumer retry loops.
