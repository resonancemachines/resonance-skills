## 1. Executive Summary & Problem Statement

The Resonance Platform's **Company Brain** acts as an enterprise-grade, decentralized cognitive backbone where human engineers and autonomous AI agents collaborate across multi-tenant organizational hierarchies (`README.md`, [`ARCHITECTURE.md`](../architecture/ARCHITECTURE.md)).

Following our foundational VFS design ([`2026-10-04-research.md`](../research/2026-10-04-research.md) and [`ADR-0007`](../adr/ADR-0007-company-brain-file-system-integration.md)), this continuation wrap-up finalizes the **Agentic Inbox/Outbox Semantic Delta Promotion Protocol**, **Cycle-Safe Cross-Workspace Symlink Resolution**, and **Content-Addressable Storage (CAS) Reference-Counted Garbage Collection**.

## 3. End-to-End Tier Interaction Design

### 3.1 Front-Office Outbox Pattern (`resonance-upload` `:8008` & `resonance-action` `:8001`)
1. **Multipart Direct-to-Store:** `resonance-upload` negotiates presigned MinIO URLs keyed by `${tenantId}/${orgId}/staging/${uploadId}`. Upon completion, the object's SHA-256 digest is verified against `vfs_blobs`. If the digest already exists for the tenant, the duplicate staging object is discarded and `ref_count` on `vfs_blobs` is incremented atomically.
2. **Transactional Outbox Emission:** Mutations (`CreateNode`, `MoveNode`, `CreateSymlink`, `PromoteAgentOutboxDelta`) write to `vfs_nodes` and `outbox_events` within a single PostgreSQL local transaction. Debezium tails the WAL and routes events to `resonance.vfs.events` keyed by `hash(tenant_id, org_id)`.

### 3.2 Middle-Office Choreographed Sagas (`resonance-workflow` `:8108`)
1. **Ingestion & Promotion Saga:** When a raw file lands in `[inbox]`, `resonance-workflow` coordinates streaming Tika extraction (`resonance-meta` `:8109`), PII tokenization (`resonance-crypto` `:8103`), and ABAC validation (`resonance-entitlement` `:8104`).
2. **Symlink Cycle & Privilege Escalation Guard:** Before activating a `VfsSymlink`, `resonance-entitlement` verifies that the actor holds `READ` permission on the target path and `LINK` permission on the source directory, while `resonance-unified-context` verifies that adding the `[:SYMLINK_TO]` edge introduces no unguarded privilege escalation.
3. **Reverse Compensation:** Any parser failure, PII vault failure, or policy rejection triggers compensating events that decrement `vfs_blobs.ref_count`, purge unreferenced MinIO blobs, and transition the VFS node to `QUARANTINED` (`resonance-support` `:8006`).

### 3.3 Back-Office & Platform Brain (`resonance-unified-context` `:9001`)
1. **Graph Cosmos Projection:** Projects `(:VfsFolder)-[:CONTAINS_NODE]->(:VfsNode)` and `(:VfsSymlink)-[:SYMLINK_TO]->(:VfsNode)` in Neo4j with mandatory `tenantId` property constraints.
2. **Cycle-Safe Scoped GraphRAG:** During hybrid retrieval (`resonance-research` `:8005` $\rightarrow$ `resonance-unified-context` `:9001`), subtree resolution traverses up to depth $D \le 10$ across `CONTAINS_NODE|SYMLINK_TO` with cycle detection, then intersects the resulting `VfsSymlink` target paths against the caller's authorized path prefixes before executing `pgvector` + `tsvector` Reciprocal Rank Fusion (RRF).

### 4.2 Cycle-Safe Symlink & Subtree GraphRAG Resolver (`resonance-unified-context`)

```java
package com.resonancemachines.context.vfs;

import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.UUID;
import org.springframework.data.neo4j.core.Neo4jClient;
import org.springframework.stereotype.Repository;
import org.springframework.transaction.annotation.Transactional;

@Repository
public class VfsScopedSubtreeRepository {

    private final Neo4jClient neo4jClient;

    public VfsScopedSubtreeRepository(Neo4jClient neo4jClient) {
        this.neo4jClient = neo4jClient;
    }

    /**
     * Resolves all CAS SHA-256 document digests contained within a VFS folder path,
     * traversing both structural CONTAINS_NODE edges and authorized SYMLINK_TO edges
     * while preventing infinite symlink cycles and cross-tenant traversal.
     */
    @Transactional(readOnly = true)
    public Set<String> resolveAuthorizedSubtreeDigests(
            UUID tenantId,
            String rootMaterializedPath,
            List<String> authorizedPathPrefixes) {

        String cypher = """
                MATCH (root:VfsNode {tenantId: $tenantId, materializedPath: $rootPath})
                MATCH path = (root)-[:CONTAINS_NODE|SYMLINK_TO*0..10]->(leaf:VfsFile {tenantId: $tenantId})
                WHERE leaf.status = 'ACTIVE'
                  AND NONE(n IN nodes(path) WHERE n.tenantId <> $tenantId)
                  AND size(nodes(path)) = size(apoc.coll.toSet(nodes(path)))
                  AND ANY(prefix IN $authorizedPrefixes WHERE leaf.materializedPath STARTS WITH prefix)
                RETURN DISTINCT leaf.sha256Checksum AS sha256Checksum
                """;

        return Set.copyOf(
                neo4jClient.query(cypher)
                        .bind(tenantId.toString()).to("tenantId")
                        .bind(rootMaterializedPath).to("rootPath")
                        .bind(authorizedPathPrefixes).to("authorizedPrefixes")
                        .fetchAs(String.class)
                        .all()
        );
    }

    @Transactional
    public void projectSymlinkEdge(UUID tenantId, UUID symlinkNodeId, UUID targetNodeId, String sourcePath) {
        String cypher = """
                MATCH (target:VfsNode {id: $targetNodeId, tenantId: $tenantId})
                MERGE (link:VfsNode:VfsSymlink {id: $symlinkNodeId, tenantId: $tenantId})
                SET link.materializedPath = $sourcePath,
                    link.status = 'ACTIVE'
                MERGE (link)-[:SYMLINK_TO {tenantId: $tenantId}]->(target)
                """;

        neo4jClient.query(cypher)
                .bind(tenantId.toString()).to("tenantId")
                .bind(symlinkNodeId.toString()).to("symlinkNodeId")
                .bind(targetNodeId.toString()).to("targetNodeId")
                .bind(sourcePath).to("sourcePath")
                .run();
    }
}
```

### 4.3 Reference-Counted CAS Blob Garbage Collector (`resonance-upload`)

```java
package com.resonancemachines.resonanceupload.cas;

import io.minio.MinioClient;
import io.minio.RemoveObjectArgs;
import java.util.UUID;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class CasBlobLifecycleService {

    private final JdbcClient jdbcClient;
    private final MinioClient minioClient;

    public CasBlobLifecycleService(JdbcClient jdbcClient, MinioClient minioClient) {
        this.jdbcClient = jdbcClient;
        this.minioClient = minioClient;
    }

    /**
     * Decrements the reference count for a tenant-scoped CAS blob during Saga compensation
     * or VFS file deletion. Physical MinIO deletion only executes when ref_count reaches 0.
     */
    @Transactional
    public boolean releaseBlobReference(UUID tenantId, String sha256Checksum, String bucketName) {
        record BlobRefState(int refCount, String objectKey) {}

        var stateOpt = jdbcClient.sql("""
                UPDATE vfs_blobs
                   SET ref_count = GREATEST(ref_count - 1, 0),
                       updated_at = now()
                 WHERE tenant_id = :tenantId
                   AND sha256_checksum = :sha256
                RETURNING ref_count, minio_object_key AS objectKey
                """)
                .param("tenantId", tenantId)
                .param("sha256", sha256Checksum)
                .query(BlobRefState.class)
                .optional();

        if (stateOpt.isPresent() && stateOpt.get().refCount() == 0) {
            try {
                minioClient.removeObject(
                        RemoveObjectArgs.builder()
                                .bucket(bucketName)
                                .object(stateOpt.get().objectKey())
                                .build()
                );
                return true;
            } catch (Exception ex) {
                throw new IllegalStateException("Failed to purge zero-ref CAS object from MinIO", ex);
            }
        }
        return false;
    }
}
```
